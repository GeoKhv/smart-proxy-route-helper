## Evidence and release decision

[Release and assets](https://github.com/GeoKhv/smart-proxy-route-helper/releases/tag/v0.4.1)
include the versioned ZIP, checksum and `compatibility-evidence-v0.4.1.zip`: raw snapshots,
CRC32C-verified WAL copies, screenshots, AX captures, server traffic, the complete request matrix,
automated results and a Russian audit report. Test data is synthetic and local.

**The reproduced P1 is fixed for the supported 0.3.2/0.4.1 contract.** Old devices cannot execute
Life connections or Life overrides of existing Work parents; that capability requires updating
them, not changing their configuration. Concurrent edits to the same generation still use
Chrome's existing conflict semantics. No unconditional mass Store rollout GO is claimed:
run signed-in two-device Sync acceptance (including offline return and conflicts) first, and
ensure users understand the [old-device boundary](../sync-compatibility.md). 0.4.0 clients must
be upgraded rather than left in the same Sync group. The GitHub artifact is available for this
remaining acceptance; Store remains unchanged.
