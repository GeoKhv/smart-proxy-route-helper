# RU permission justifications — 0.4.2

## `proxy`

```text
Применяет и проверяет PAC, созданную локально из подтверждённых пользователем доменных правил и локальных подключений Proxy/DIRECT. Читает состояние управления Chrome Proxy, поддерживает паузу и ручную проверку выбранного маршрута. Удалённая PAC и удалённая логика не используются.
```

## `storage`

```text
Хранит названия маршрутов, доменные правила, настройки классификации, части списков и записи согласования переносов в chrome.storage.sync. Подключения, пауза, язык и одна копия исходных настроек остаются локально. Session storage содержит временные метаданные записи, без списков найденных hostname. Содержимое страниц/файлов и учётные данные прокси не хранятся.
```

## `activeTab`

```text
Даёт временный доступ к текущей странице после обращения к расширению через панель инструментов: управление маршрутом сайта, ручная проверка, предпросмотр hostname и временная запись. Постоянный доступ ко всем сайтам и широкие host permissions не запрашиваются.
```

## `scripting`

```text
Запускает временные скрипты из пакета только по явной команде. Предпросмотр и ограниченная запись сводят ссылки ресурсов к hostname. Проверка маршрута делает запрос к текущему origin без cookies и учётных данных, чтения DOM/тела ответа и переходов по редиректам. Нет постоянных content scripts, удалённого кода, установки сертификатов или обхода TLS.
```

Manifest: proxy, storage, activeTab, scripting. No host_permissions, <all_urls>, webRequest, webNavigation or persistent content scripts. Review risks remain proxy control, script injection and disclosure consistency; unchanged permissions do not guarantee approval.
