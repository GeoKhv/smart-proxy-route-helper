# Smart Proxy Route Helper v0.3.2 Release Notes

## English

- Fixed a Chrome Sync verification issue that could prevent adding, editing, or removing routing rules on some Chrome profiles.
- Added a quick Pause / Resume control in the popup to temporarily stop proxy routing without disabling the extension or deleting rules.
- Improved error handling for routing-rule changes so storage failures are shown in the UI instead of failing silently.

## Русский

- Исправлена ошибка проверки Chrome Sync, из-за которой на некоторых профилях Chrome нельзя было добавлять, изменять или удалять правила маршрутизации.
- В popup добавлено быстрое переключение Pause / Resume, позволяющее временно приостановить прокси-маршрутизацию без отключения расширения и удаления правил.
- Улучшена обработка ошибок при изменении правил: проблемы хранилища теперь показываются в интерфейсе, а не остаются незаметными.
