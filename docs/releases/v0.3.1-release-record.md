## Confirmed manual smoke

On `0.3.1`, the release owner manually confirmed that all of the following scenarios completed
correctly, with no errors or regressions observed:

- exact-rule routing;
- include-subdomains routing;
- direct connection for sites without a rule;
- `Check via proxy`;
- changing routing state while diagnostics are running;
- restoring the latest applicable PAC after diagnostics;
- restarting diagnostics without hanging;
- exporting and importing settings;
- import messages in Russian and English;
- `Auto`, `English`, and `Русский` language selection;
- adding and removing a domain;
- upgrading `exact` to `include-subdomains`;
- duplicate prevention;
- mixed batch handling.
- Popup width on the problematic Chrome profile.

The Popup width scenario passed on the problematic Chrome profile. The other scenarios preserve
the earlier manual smoke history for the final release context.

## v0.3.1 bugfixes

- Chrome Sync per-item quota handling now stores routing rules in chunks and safely migrates
  legacy single-item data.
- The Action Popup root width is explicitly constrained so the popup does not stretch on affected
  Chrome profiles.
