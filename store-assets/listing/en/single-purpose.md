# English single purpose — submitted for 0.4.2

```text
Smart Proxy Route Helper manages explicit per-site routing in Chrome through user-configured named proxy connections or DIRECT. It generates PAC routing locally, keeps connections device-specific, synchronizes domain settings through Chrome, and provides user-invoked current-site controls and optional hostname diagnostics. It does not provide a VPN or proxy server, collect telemetry, run a developer backend, or add rules automatically.
```
